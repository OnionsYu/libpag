# Photoshop 快照到 PAGX 的转换约定

## 数据与依赖

`include/photoshop/Document.h` 是宿主无关的源模型，不依赖 Photoshop SDK 或 PAGX。
`PhotoshopImporter` 负责分析与转换，输出已有 `PAGXDocument`；XML 由 `PAGXExporter`
生成。核心入口接收 Photoshop 采集的快照，不解析 PSD 文件像素或合成缓存。

桥接协议版本为 2，源快照版本为 4（兼容 v1/v2/v3）。图层树按从底到顶排列，所有边界采用文档像素坐标，保留负坐标及小数。
Opacity、Fill 和颜色分量为 0～1。`compositingKnown=false` 表示合成信息未知，不能
视为 Normal。`features` 保存当前转换器无法原生表达的能力标记。隐藏子树不参与当前
状态输出，但仍受结构校验。该导出不保证修改可见性后的其他状态等价。

源模型保存图层身份与源属性；派生资源保存 Photoshop 实际渲染结果。二者不得混用。
矩形原生映射仅接受适配器已验证的 `SolidRectangle`，不得从普通图层 bounds 猜测形状。

v2 增加 `Shape`：有序路径组件、Add/Subtract/Intersect/Exclude、组件 winding 规则、
子路径闭合状态及 anchor/incoming/outgoing 绝对控制点。控制点已经包含 Photoshop
变换，不再应用 live-shape origin 的 transform。布尔运算保持矢量几何；初始减法、
含开放路径的多组件布尔运算目前回退。颜色和实线描边保存为源属性，不混入图像资源。
Fill 透明度作用于填充，图层 Opacity 作用于填充与描边的组合。`rasterFeatures` 表示
已确认仅影响本层的外观；`features` 表示未能证明背景独立的语义。二者不能互换。

v3 将 `Shape.fill` 和 `Stroke.paint` 统一为带 `kind` 的 Paint。纯色保存 RGBA；渐变
独立保存颜色/透明度标记、位置、中点、平滑度、插值方法、反向、抖动及单位渐变到文档
像素的完整仿射矩阵，不提前混成一组 PAGX 色标。旧版本的颜色对象由传输层升级，
不让运行时同时解释多套格式。模型可保存的语义与已通过宿主验证的能力分别判断。
未知的渐变插值不视为线性；当前渐变仍局部回退，保留完整已解码属性供后续映射。

v4 增加独立 `VectorMask`，保存 enabled、linked、inverted、initialFill、density、feather
及文档坐标路径组件，
与填充层自身的 Shape 分开。禁用蒙版不参与当前状态渲染；已验证的封闭硬蒙版使用
独立 Contour 节点，保留组内矢量、布尔孔洞及组透明度。Linked 仅为编辑元数据，不能
据此重复应用变换。反相使用导出画布内的几何补集；羽化、非满密度、初始填满、初始非
Add、空/开放蒙版仍回退；启用蒙版的穿透组
连同所需背景采集。带独立蒙版的文字仍回退，避免轮廓化替换原蒙版。

无矢量蒙版的填充层使用 `Layer.fill`，保留 Fill 图层种类；其绘制范围是明确的导出
画布，不是图层像素边界。有像素蒙版等未映射外观时仍按本层回退。
形状虚线在描述符中使用真正的点单位，以 `strokeStyleResolution / 72` 换算为像素，
不能按 UI 显示的描边宽度倍数解释。当前原生支持单组件、居中描边；圆/方端帽的间隙
小于描边宽度时回退，避免重叠端帽覆盖率差异。路径布尔运算可能改变轮廓起点，
未验证的布尔虚线、非居中虚线均回退。非默认 `strokeStyleOpacity` 在实测宿主中
未按描述符值合成，因此保留源值但不直接映射成 PAGX alpha。

宿主适配器使用 action `json` 属性读取高级混合信息，并以普通 layer/path 描述符读取
像素单位、蒙版、纯色和描边。普通 layer get 会漏掉非默认高级混合属性。仅在实测的
Photoshop 27.4 / JSON 1.6.1 契约内把缺失的高级混合属性解释为默认；其他情况仍是未知。
另读 application `colorSettings.RGBBlendGamma`，只有实测的 `false` 才通过矢量门禁。
启用、缺字段或读取失败均写入文档 `features` 并回退整图；不能因图层是 Normal 就忽略
全局混合环境。此查询不修改用户颜色设置。

Photoshop 27.4 的 layer/path get 和 action JSON 均会遗漏 `vmsk` 的反相标志。
宿主在需要矢量蒙版状态时，将工作文档另存为插件临时目录内的 PSD 副本，按图层 ID
读取 `vmsk`/`vsms` flags 与 selector 8 初始填充记录，再与描述符的 enabled/linked
交叉校验。只读取图层元数据，跳过像素通道和合成缓存；读取量限制为 32 MiB，每块读取
不超过 53,248 字节，文件句柄与临时文件在 finally 清理。当前辅助读取器仅验证 8-bit
PSD v1；保存/读取失败、未来格式、未知标志或状态冲突均局部回退，不猜测缺失标志。
该步骤增加一次临时保存开销。反相形状的填充/描边组合仍回退；独立硬蒙版的反相保留矢量。
格式依据为 [Adobe PSD 规范](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)，
分块读取使用 [UXP fs API](https://developer.adobe.com/photoshop/uxp/2021/uxp/reference-js/Modules/FileSystem/)。

PAGX 的填充规则属于 Fill，不属于 PathData。EvenOdd 形状的内外描边因此使用双倍宽度
的居中 Stroke 和独立矢量 Contour 蒙版；外描边使用包围完整描边范围的有限补集。
蒙版不携带源 Fill/Opacity，填充、描边透明度和最终图层透明度各自只应用一次。
这一构造保持贝塞尔路径与描边参数，不以猜测轮廓方向消除孔洞。

## 分析和采集

`Analyze` 返回渲染请求、统计和诊断。计划以可证明的合成隔离边界为单位：

1. 受支持且背景独立的形状和文字轮廓直接生成矢量；独立像素层保留位图。
2. 已知局部外观（如蒙版或未映射的填充）采集本层/组子树。组自身透明度在图像内烘焙。
3. 剪贴层与其基底之间的连续兄弟范围一起采集；调整或特殊混合层包含隔离边界内此前的
   所有背景。相交范围合并，穿透组中的背景依赖向外传播，普通隔离组阻断该传播。
4. 未知合成、挖空或文档级颜色/精度变化回退完整文档。核心对画板同样要求整图，
   当前宿主入口则在采集前明确拒绝画板。用户选择外观快照也使用整图。

这是保守的连续依赖范围，不承诺几何上最小范围。请求的 `layerIds` 按源顺序列出直接
兄弟，`parentId` 指定其父组，`layerId` 是首个兄弟。转换器用一张图像**替换**整个范围，
不再输出被覆盖的原内容；范围外的矢量和祖先结构继续保留。整图请求的这些字段为空。

已验证的 Normal、Multiply、Screen、Darken、Lighten、Overlay、Hard Light、Exclusion
由 PAGX 在同一隔离边界原生混合。读取背景本身不等于必须采集背景；只有未映射的混合
或内容才要求范围回退。普通组显式隔离；满足条件的 Pass Through 组保留背景穿透。
一旦原生混合层进入剪贴采集范围，该范围仍必须包含所需背景，不能先在透明背景烘焙
再丢弃原混合模式。Soft Light 未通过现有像素误差门槛，继续范围回退。

局部采集在临时文档中恢复目标范围及后代的源可见性，隐藏无关内容，仅打开必要祖先。
祖先组不透明度暂设为 100%，从**文档合成结果**读取像素；被采集根层自身 Opacity、Fill、
蒙版和变换已经烘焙，转换器不再应用。未被采集的祖先透明度由 PAGX 组应用一次。
每次采集都恢复原始透明度，防止前一次采集的祖先中和影响后续组采集。
原生祖先矢量蒙版也在局部采集时禁用，由 PAGX 祖先裁剪一次；每次采集恢复非祖先的
原始蒙版启用状态，被采集根层自身的蒙版仍烘焙。中和失败即中止，不输出重复裁剪结果。
直接读取 `getPixels(layerID)` 不能未经验证就视为满足此契约。

图像为 1:1 像素、sRGB、保留透明度的 PNG。边界必须使用宿主实际返回值。完全透明
的结果使用空字节和零宽高，不以任意错误代替透明结果。非 sRGB/8-bit RGB 文档走
宿主合成与明确的色彩转换；当前宿主入口拒绝 32-bit HDR，不能以截断代替色调映射。

## PAGX 输出

- 根画布大小来自明确的导出矩形；导出原点平移到 `(0, 0)`。
- 普通组使用嵌套 Layer，组本身位于文档原点，不从内容 bounds 推导二次位移。
- 位图使用 Image、Rectangle、ImagePattern 和 Fill；叶子的 alpha 保持 1。
- 相同 PNG 资源去重，资源内嵌，不引用插件临时路径。
- 已验证纯色矩形保留几何；Opacity 在 Layer 上应用，Fill 在 Fill 上应用。
- Pass Through 组只有透明度与 Fill 均为 1、无局部蒙版且后代没有向外背景依赖时才保留。
- 非空诊断不等于导出失败，但必须在面板或报告中显示结构降级范围。

## 完整性审查与能力矩阵（2026-11-12）

审查范围为 `1bde74d440b6b941e410958cdd72b8a12b34b49f` 至
`b8baf65256fcbc0c1728f9a13d7a60778c0ac315`，包含两端共 10 个提交。
该范围建立了宿主采集、源模型、矢量路径、单色文字轮廓、合成回退及报告链路，
但**没有完整实现 PSD 的矢量特性转换**。复合路径内外描边的填充规则、全局混合
gamma、独立矢量蒙版状态均存在正确性或覆盖缺口；纯色以外的 Paint、虚线、原生混合
及独立蒙版也不能由当时的普通路径支持推导为已支持。

后续四个实现阶段分别补齐描边与混合环境、Paint 模型与合格虚线、原生混合与组隔离、
独立硬蒙版。当前范围如下；“原生”表示通过能力判断后输出 PAGX 几何/合成节点，
不表示保留全部 Photoshop 编辑参数，也不表示任意组合均已验证。
原生宿主契约限定为 Photoshop 27.4、JSON 1.6.1、RGB/sRGB/8 位、RGBBlendGamma=false。

| 特性 | 当前结果 | 条件或尚缺语义 |
| --- | --- | --- |
| 贝塞尔路径、复合路径、孔洞 | 原生几何 | 保留文档坐标和填充规则；首组件非 Add、开放路径参与多组件布尔运算回退 |
| 纯色形状与无蒙版填充层 | 原生 Fill | 无蒙版填充使用导出画布；不从像素 bounds 猜测矩形 |
| 实线描边、内外描边 | 原生 Stroke / Contour | 保留宽度、端帽、连接；非默认描边透明度、像素对齐等未验证外观回退 |
| 虚线描边 | 有条件原生 | 单组件、居中、实际点单位；圆/方端帽间隙不得小于宽度 |
| 渐变、图案填充/描边 | 局部或依赖范围回退 | 渐变仅部分源属性已解码；尚无通过宿主验收的原生映射，图案资源模型仍缺失 |
| 独立硬矢量蒙版、反相 | 有条件原生 Contour | 已确认 flags、闭合路径、满密度、零羽化、初始未填满；禁用蒙版忽略 |
| 羽化/密度蒙版、像素蒙版 | 局部或依赖范围回退 | 当前不保留独立软蒙版；像素层/智能对象的矢量蒙版也随内容烘焙 |
| Normal 及 7 种非 Normal 混合 | 有条件原生 | Multiply、Screen、Darken、Lighten、Overlay、Hard Light、Exclusion；内容和隔离边界也须合格 |
| 普通组、Pass Through 组 | 有条件保留层级与隔离 | 穿透组须 Opacity/Fill=1、无启用蒙版且无向外的采集依赖 |
| 剪贴链、调整层、图层样式、其他混合 | 连续依赖范围回退 | 包含需要的背景；Soft Light 已实测超出原生误差门槛 |
| 单色文字 | 宿主生成的矢量轮廓 | 不保留文字编辑、字体 hinting；混色、变形、缺字体及带独立蒙版的文字回退 |
| 参数形状、智能对象内部结构 | 未保留编辑语义 | 参数形状只输出最终几何；智能对象由 Photoshop 渲染 |
| 16 位、非 sRGB 或非 RGB | 整图采集并转为 8 位 sRGB | 已实测 RGB 8/16 位；其他模式和 ICC 尚无完整宿主矩阵 |
| 未知合成、挖空、未验证的宿主/混合 gamma | 整图回退 | 不把缺失字段解释为已确认的默认值 |
| 画板、非方形像素、32 位 HDR、1 位位图 | 宿主入口明确拒绝 | 尚无相应导出坐标、采样或颜色策略 |

输出针对当前可见状态；不支持 PSD 回写、完整编辑状态或任意 PSD 的纯矢量导出。
位图回退的参考验证为 1×，不能据此承诺任意放大后的矢量质量。

## 后续扩展方案

保持“宿主事实 → 版本化源模型 → 能力判断/依赖计划 → PAGX 节点 → 序列化”的分层。
`src/pagx/html/importer` 已使用渐变、ImagePattern、Contour/Alpha 蒙版和混合节点，
说明目标格式有相关表达能力；HTML/CSS 的色标插值、盒坐标和裁剪语义不能直接替代
Photoshop 的源语义。只有证明输入含义一致的几何、资源和节点构造才适合提取公共代码。

尚未实现的扩展按以下顺序推进，每项在独立提交中通过验收后再扩大能力判断：

1. **渐变和图案。** 补齐径向等类型、对齐与变换、颜色/透明度中点、Classic/Linear/
   Perceptual 插值和平滑/抖动契约。确定 PAGX 可精确表达的子集；需要近似时单独标识
   误差，不能直接把源色标当作 PAGX 色标。图案须取得实际资源、平铺矩阵与相位，再映射
   ImagePattern；它可保留矢量边界，但图案本身仍是图像资源。无法验证时沿用回退。
2. **剪贴与软蒙版。** 分开几何覆盖、内容 alpha、蒙版密度/羽化和组透明度，先实现能
   证明等价的独立蒙版及剪贴子集。覆盖半透明基底、嵌套组、反相、背景混合及一次性 alpha
   应用；未确认高级混合语义时继续采集完整依赖范围。
3. **文字与嵌套内容。** 多色轮廓需确定文字 run 与字形几何/绘制顺序的对应关系；
   可编辑 Text 另行建立字体、排版、kerning 和换行契约。智能对象递归导入与画板必须先
   定义源坐标、变换、裁剪、背景、资源循环和缺失依赖，不能仅将渲染 bounds 作为结构。

每项验收同时检查结构和外观：独立 Photoshop 1×/4× 分层参考、PAGX XML 往返、
Image/Path 数量、alpha/黑底/白底误差及降级诊断。当前图形比较门槛为 MAE≤0.5/255、
边缘最大差≤64/255、参考平坦区域最大差≤2/255；失败应缩小原生支持范围或修正语义，
不得为通过样例放宽门槛。文字轮廓与 Photoshop 字体 hinting 的差异单独披露。

当前已完成 20 项 C++、30 项 Node 测试；最终宿主回归含 8 个原生场景的 1×/4× 对照
及 5 个回退场景的 1× 对照，均通过既定门槛。各阶段样例、命令与环境见
[插件验证记录](../tools/photoshop-exporter/README.md#分阶段验证)。
